Teaching from more than one machine?

Anonymous sign-in gives each browser its own ID, so a laptop, the projector and a staffroom machine would each count as a different person. Sign in with a teacher account instead and the same identity follows you everywhere. Create the account once in the Firebase console under Authentication, Users, Add user.

The teacher list is still open, so anyone opening this link could make themselves a teacher. Close it before you hand the link to a class.
